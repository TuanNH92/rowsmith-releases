# Rowsmith

SQL client native, nhanh, đa nền tảng: PostgreSQL, MySQL/MariaDB, SQLite, SQL Server, DuckDB…

Repo này chỉ chứa **bản cài đặt** và thông tin cập nhật tự động. Mã nguồn không công khai.

## Tải về

Vào **[Releases mới nhất](https://github.com/TuanNH92/rowsmith-releases/releases/latest)**:

| Hệ điều hành | File |
| --- | --- |
| Windows 10/11 (64-bit) | `rowsmith-<version>-x64-setup.exe` |
| macOS (Apple Silicon & Intel) | `Rowsmith-<version>-universal.dmg` |
| Ubuntu/Debian | `rowsmith_<version>_amd64.deb` |

### Windows
Chạy file `setup.exe`. Nếu Windows SmartScreen cảnh báo, chọn **More info → Run anyway** (bản cài chưa ký số Microsoft).

### macOS
Mở file `.dmg`, kéo **Rowsmith** vào **Applications**. Lần đầu mở, nếu macOS chặn: vào **System Settings → Privacy & Security → Open Anyway**.

## Cập nhật

App tự kiểm tra bản mới. Mỗi bản cập nhật được ký bằng khóa ed25519 (minisign); app chỉ cài bản có chữ ký hợp lệ.
